Indentificadores para variaveis:

    • podem começar com letra, $ ou _

    • não pode começar com Numeros

    • não pode ser palavras reservadas

exemplo: var, function e nenhuma palavra que seja um comando

Aula 6: {Manipulação de dados}

Comentarios nas 3 linguagens:

   • <!-- --> = HTML

   • /**/ = CSS

   • // e /**/ = JS

Conversão String > Numero:
    Number.parseInt(n)   - para Numeros Inteiros
    Number.parseFloat(n) - para Numeros Reais
    Number(n)            - para Numeros inteiros e reais

Formatando String:
var s = 'Javascript'

    'Eu estou aprendendo s'    - não faz interpolação
    'Eu estou aprendendo' + s  - usa Concatenação
    `Eu estou aprendendo ${s}` - usa template string (template string só funciona com crase)


    s.lenght             - para quantos caracteres a string tem
    s.toUpperCase()      - tudo para 'MAIUSCULAS'
    s.toLowerCase()      - tudo para 'minusculas'

Formatando Numeros:
var n1 = 1545.5

    n1.toFixed(2)                                                   - para fixo com 2 casas
    n1.toFixed(2).replace('.',',')                                  - para trocar o ponto dos numeros
    n1.toLocaleString('pt-BR',{style: 'currency', currency: 'BRL'}) - para colocar o numero como tipo de moeda

(number + number) para Adição
(string + string) para Concatenação

|   ()

V

FORMA LONGA         FORMA SIMPLIFICADA      OPERACAO
n = n + 4        ->   n += 4                Soma
n = n - 5        ->   n -= 5                Subtracao

n = n ** 2       ->   n **= 2               Potenciacao (exponenciacao)
